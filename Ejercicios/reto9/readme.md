# CICD Ejercicios

![CI](https://github.com/Danielb2a/CICDretos/actions/workflows/ci.yml/badge.svg)

Este repositorio contiene los retos de C con integración continua usando GitHub Actions.

## Descripción
- Los retos implementan funciones en C con pruebas unitarias.
- La integración continua verifica la compilación y tests en GitHub Actions.
- El badge de CI indica si el workflow está pasando ✅ o fallando ❌.
